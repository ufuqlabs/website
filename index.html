6-Month Bootcamp

Your DevOps Journey

A step-by-step path from foundations to a full-time role. Every phase builds on the last — nothing is filler.

PHASE 01 · WEEKS 1–2

Linux Fundamentals

Commands, users, permissions, system management. The foundation everything else is built on.

PHASE 02 · WEEKS 3–4

Git & GitHub

Version control, branching, merging, collaboration workflows used in every professional team.

PHASE 03 · WEEKS 5–6

Shell Scripting (Bash)

Automate repetitive tasks and write scripts that actually run in production environments.

PHASE 04 · WEEKS 7–8

Networking

TCP/IP, DNS, HTTP, firewalls and troubleshooting — the knowledge that separates DevOps from developers.

PHASE 05 · WEEKS 9–10

Docker & Containers

Build, share and run containers. Images, volumes, compose, and real best practices.

PHASE 06 · WEEKS 11–13

AWS Cloud

EC2, S3, VPC, IAM and deploying real-world applications. Includes AWS Solutions Architect prep.

PHASE 07 · WEEKS 14–15

Terraform (IaC)

Provision and manage cloud infrastructure safely and repeatably — the new standard for teams at scale.

PHASE 08 · WEEKS 16–17

CI/CD Pipelines

Automate build, test, and deployment cycles with GitHub Actions and Jenkins.

PHASE 09 · WEEKS 18–20

Kubernetes

Deploy, scale and manage containerised workloads. CKA exam prep included.

PHASE 10 · WEEKS 21–22

Grafana & Monitoring

Visualise metrics, build dashboards, and observe infrastructure like a senior SRE.

PHASE 11 · WEEKS 23–24

Golang (Advanced)

Build powerful, concurrent, scalable tools in Go — the language behind Kubernetes, Docker and Terraform.

About Ufuq Labs

We Started with a
Simple Conviction

Ufuq (أفق) means horizon in Arabic. We chose it because we believe that for any driven person — regardless of their starting point — a high-growth tech career is on the horizon. It's not a matter of background, it's a matter of the right environment and the right support.

Ufuq Labs was built to be that environment: practical, rigorous, and relentlessly focused on your outcome. Our instructors have shipped infrastructure at scale. They know what companies actually hire for — and we've built a program around exactly that.
